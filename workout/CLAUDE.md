# CLAUDE.md: workout folder

This folder is Isaac's **personal lifting / workout app**. It is a separate project from:
- the Aggie Success Coach Toolkit (root `index.html`)
- `Peer Success Coach/` (work)
- `School/`

Keep it self-contained: don't link it from the toolkit, and don't reuse or change files in the work or school folders.

## Public, so keep it general
This folder is in the public repo and auto-syncs to GitHub every ~5 minutes. The app's code and generic exercise info are fine here. Personal health details (weight, injuries, medical info) should not be hard-coded into files. If the app saves lifts or logs, save them on the phone (in the browser), not in this repo.
